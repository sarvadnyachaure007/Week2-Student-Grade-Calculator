
# Week 2: Student Grade Calculator

## Project Description
A simple Python program that accepts a student's name and marks,
calculates their grade, and displays an encouraging message.

## Requirements
- Python 3.8 or later
- No additional libraries required

## Grading Rules

| Marks | Grade |
|---|---|
| 90–100 | A |
| 80–89.99 | B |
| 70–79.99 | C |
| 60–69.99 | D |
| 0–59.99 | F |

## Features
- Uses if-elif-else statements.
- Uses functions for reusable code.
- Validates marks between 0 and 100.
- Uses a while loop for invalid input.
- Handles non-numeric input using try-except.
- Displays an encouraging message for every grade.

## How to Run

1. Install Python 3 if it is not already installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run:

   python grade_calculator.py

On Windows, you can also use:

   py grade_calculator.py

## Example Output
